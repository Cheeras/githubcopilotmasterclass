# How to create a GitHub Copilot skill?

﻿

## What is the Skill?

* A skill is a set of instructions which will enhance the capability of a large language model by teaching them the repetitive task,  knowledge, workflows, and giving them an instruction what to do next.

﻿

SKILL.md ->   the format that we use is Markdown

﻿

**What is MD file or Markdown file?**

 Markdown is basically a plain English file with a formatting. You can basically format it and preview it. It will render it properly in a way

﻿[﻿stackedit.io/](https://stackedit.io/)

my-skill/

├── assets/ # Optional: templates, resources
└── ... # Any additional files or directories
